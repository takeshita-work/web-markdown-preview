# 機能一覧

## フォルダ / ファイル選択

- **📂 フォルダを選択** … `showDirectoryPicker()` でネイティブのフォルダ選択。配下の `.md` / `.html`（`.htm`）/ `.pdf` を再帰収集してツリー表示（`node_modules` / `.git` は除外）。

## ファイルツリー（左サイドバー）

- `.md` / `.html`（`.htm`）/ `.pdf` のみ表示。ファイル名の先頭に種別アイコン。
- 起動時は全フォルダ閉じた状態。
- フォルダ展開時、子が**単一のサブフォルダのみ**なら連鎖的に自動展開。
- ファイルを開くと、ツリーがそのファイルまで自動展開・スクロール。

### 一時的な非表示

- ファイル / フォルダを**右クリック →「アイテムを非表示」**でツリーから隠せる。フォルダを隠すと**配下ごと**消える。
- ツリーの**何もない所を右クリック →「非表示にしたものを表示する（N 件）」**で全部戻す。
- 非表示のアイテムがあるときは、サイドバー見出しのフォルダ名の後ろに**小さな点（•）**が付く（件数は tooltip で確認）。非表示が無いときは「非表示にしたものはありません」と出る。
- **表示だけの絞り込み**で、開いているタブ・プレビュー・CSS の検索対象には影響しない（開いたままのファイルを隠してもタブは残る）。
- ディレクトリの定期更新を跨いでも保たれる。**別のフォルダを開くと解除**される（保存はしない）。

## タブ（仮選択 / 確定選択）

VS Code のプレビュータブ方式。

| 操作 | 動作 |
|---|---|
| シングルクリック | **仮選択**（斜体）。別ファイルを選ぶと置き換わる |
| ダブルクリック（ツリー / タブ） | **確定選択**（pin）。以後消えない |
| 中クリック / × | 閉じる |

- 同名ファイルを複数開くと、タブ名が **`親フォルダ/ファイル名`** 形式になり区別される（ツールチップにフルパス）。
- アクティブタブの背景色はヘッダーと同色で一体化。

## 画面の 2 分割（ペイン）

- ツールバー右の **分割ボタン**でメイン領域を左右 2 つのペインに分ける。**ペインごとに独立したタブバー**を持つ（VS Code のエディタグループ相当）。
- **フォーカス中のペイン**（タブバーが青くなる方）に、ヘッダーのコントロール（履歴 / 再読み込み / ソース / 印刷 / ズーム / 表示）と見出しアウトラインが追従する。**ペイン内をクリックするか、そのペインでホイール操作をする**とフォーカスが移る（プレビュー本文の上でも効く）。
- ツリーからファイルを開くと**フォーカス中のペイン**に入る。
- **タブを右寄りにドラッグ＆ドロップすると分割が始まる**（未分割時。ドロップ先の目印が出る）。分割中はもう一方のペインへドラッグして移動できる。
- タブの右クリックメニュー **「右のペインへ移動（分割）」「左のペインへ移動」** でも移動でき、選んだ瞬間に移動する。
- 境界のスプリッタをドラッグして**左右の幅を変えられる**。
- **タブを閉じてペインが空になっても分割は保つ**。空のペインをクリックしてアクティブにし、そのままツリーからファイルを選べば**そこに開く**（空ペインには「ファイルを選択してください」、分割中の非アクティブ側には「クリックしてから、ファイルを選択してください」と出る）。
- **タブを移動して移動元が空になった場合は分割を解除**し、残った側へタブを引き取る（ただし「右のペインへ移動（分割）」で分割を開いた直後は解除しない）。
- 分割ボタンをもう一度押しても解除でき、**右ペインのタブは左に引き取られる**。すべてのタブを閉じたときは 1 画面に戻り、見出しアウトラインも空になる。ヘッダーのコントロールは無効表示になる。
- 同じファイルを左右両方に同時に開くことはできない（タブはファイル 1 つにつき 1 枚。既に開いていればそのペインへ切り替わる）。

## HTML プレビュー

`.html` / `.htm` は **Markdown に変換せず、生の HTML をそのまま** iframe に描画する。

File System Access API 環境では相対パス参照がそのままでは解決できないため、描画前に参照先をローカルファイルの blob URL へ差し替える。

| 参照 | 解決タイミング |
|---|---|
| `<img src>` | 表示領域に入った時（遅延読み込み。大量画像でのメモリ枯渇対策） |
| `<link href>` / `<script src>` | 描画前に即時 → **相対 CSS / JS も効く** |
| `<video>` / `<audio>` / `<source>` の `src`、`<video poster>` | 描画前に即時 |
| `style="... url(...)"` の背景画像 | 描画前に即時 |
| ページ内スクリプトが実行時に組み立てる `src` | `HTMLImageElement` 等の `src` セッターを乗っ取り、親フレームへ問い合わせて解決 |

- 「表示」セレクトの CSS / marp テーマ選択は **HTML には適用されない**（文書自身のスタイルがそのまま使われる）。
- ソース表示・見出しアウトライン・ズーム・ライブリロード・印刷は Markdown と同様に機能する。

## 表示モード（標準 / marp / CSS テーマ）

- ヘッダー右側の「表示」セレクトで切替。**タブごと**に保持。
- 既定はファイル内容から自動判定：
  - 標準ファイル → 既定 CSS（`markdown-preview` 系を優先）
  - marp ファイル → frontmatter の `theme:`（登録済みなら）／無ければ「marp（frontmatter / 既定）」
- 現在のタブの既定にあたる選択肢には **`(default)`** マーカーが動的に付く。
- 選択肢のパスが長い場合は **`先頭フォルダ/…/親フォルダ/ファイル名`** の形に省略表示する（セレクトの幅も上限つき）。**完全なパスは tooltip** で確認できる。
- 標準フォーマットは**グレー背景＋白いカード**、marp は**スライド中央寄せ・スライド間に余白**で表示。
- 標準表示では、選択 CSS の**前に最小限の土台 CSS**（コードブロックの `padding` / `border-radius` と端での折り返し、表のセルの `overflow-wrap:anywhere`）を敷く。長い URL を含む表がシートからはみ出すのを防ぐ。VS Code の `markdown.styles` のような**上書き専用 CSS**はエディタ組み込みの CSS を前提に色だけを指定していることが多く、そのままではコードブロックの余白が失われるため。`!important` を使わず前に置くだけなので、`github-markdown.css` のような完全なテーマを選んだ場合はテーマ側の指定が優先される。
- コードブロックは**ソースの 1 行ごとにブロック化**され、**折り返した行の行間は詰めたまま、改行（論理行）の間だけ少し余白**が入る。空行も 1 行分の高さを保つ。選択範囲のソースコピーでは元のテキストがそのまま復元される。

## CSS の検索フォルダ（フォルダごとに保存）

- **☰ メニューの「CSS の設定」** で、`.css` を探すフォルダを**開いているフォルダ以下**から選ぶ。現在の指定はダイアログを開くと確認できる（選択中のフォルダがチップで並ぶ）。
- **チェックボックスで複数選択できる**。チェックしたフォルダ**以下**の `.css` だけが「表示」セレクトの候補になる（**標準 CSS / marp テーマの両方**）。対象外は読み込み自体を行わないので、`node_modules` 相当の大量の CSS を含むリポジトリでは起動も速くなる。
- `.css` を含むフォルダを**ツリー一覧**で表示する（階層をたどる操作は不要）。`▸` / `▾` またはフォルダ名クリックで開閉し、`(n)` に配下の `.css` 数が出る。どの階層の行でもチェックできる。
- 途中に**中身が 1 つしかない階層は自動でまとめて 1 行**にする（例: `external_x/…/admin`）。深いリポジトリでも一覧が短くなる。ラベルは省略表示、完全なパスは tooltip に出る。
- ダイアログを開くと、**選択済みフォルダの親は自動で展開**されるので現在の指定がすぐ見える。
- 上位フォルダを選ぶと**配下の選択は自動で畳まれる**（配下の行は「上位フォルダで選択済み」として操作不可になる）。
- 選択中のフォルダはダイアログ下部に**チップ**で並び、`×` で個別に外せる。**未選択＝ルート以下すべて**が対象。
- ツリーに出ないドット始まりのフォルダ（`.vscode` など）も選べる。
- 設定は**ブラウザ（localStorage）にフォルダごと**に保存され、次回同じフォルダを開くと復元される。**別のフォルダを開けば別の設定**になる。
- 指定フォルダに `.css` が無い場合は通知が出る。指定から外れた CSS を選んでいたタブは既定の CSS に戻る。
- File System Access API はフルパスを返さないため、キーは**フォルダ名**。同名の別フォルダは同じ設定を共有する。

## ソース表示

- ヘッダーの **`</>`** ボタン、またはプレビュー右クリックメニューで、レンダリング ⇄ ソース表示を切替（**タブごと**に保持）。
- ソース表示でも見出しアウトラインが機能する。
- ソース表示の地色は**白**（レンダリング表示のグレー地とは別）。

## 見出しアウトライン（右サイドバー）

- 見出し（h1〜h6）を**折りたたみ可能なツリー**で表示。
- クリックで該当見出しへスクロール。
- プレビューのスクロールに追従し、**現在位置の見出しをハイライト**。
- レンダリング / ソース表示の両方で機能。

## 拡大・縮小（ズーム）

- **タブごと × 表示モード（レンダリング / ソース）ごと**に保持（各既定 100%）。分割時は**左右で別々の倍率**を持てる。
- **Ctrl + ホイールと Ctrl+Shift+± は「操作したペイン」に効く**（フォーカスしていない側でも、カーソルがある方が拡大縮小される）。ヘッダーの `[−][倍率][＋]` はフォーカス中（メイン）ペインに効き、倍率表示もそちらを示す。
- 操作方法：
  - ヘッダー右側の **`[−][倍率][＋]`**（一体化 UI）
  - 倍率セレクトで直接選択
  - **Ctrl + ホイール**
  - **Ctrl + Shift + `+` / `-` / `0`**（0 でリセット）
- 段階は切りのいい値（…75/80/90/100/110/125…）。
- 標準 / ソース表示は `body` を `transform: scale()`（レイアウト幅は 100% 時の幅に固定）、marp は SVG スライドの寸法を直接スケール。いずれも**折り返しは変わらず**、見た目だけが拡大縮小される。
- **拡大位置を保持**：Ctrl + ホイールは**カーソル位置**、ヘッダーの UI / ショートカットは**表示領域の中央**にある内容が動かないようスクロール位置を補正する（縦横とも）。
- 拡大すると横スクロールバーが出る。縮小時は中央寄せで表示。
- 印刷 / PDF 出力は画面のズームを持ち込まず、常に 100% 相当で出力する。
- プレビュー枠の幅が変わったとき（ウィンドウ / サイドバーのリサイズ）はレイアウト幅を測り直して折り返しを追従させる。

## 画面移動（パン）

- **スペースキーを押しながらドラッグ**すると、つかんだ位置を保つように上下左右へスクロールできる（拡大して横スクロールが出ているときに便利）。
- スペース押下中はカーソルが `grab`、ドラッグ中は `grabbing` になる。押している間は何度でもドラッグできる。分割時は**左右どちらのペインでもドラッグでき**、カーソル表示も両方に出る（ドラッグした側だけが動く）。
- 入力欄・ボタン・リンクなどにフォーカスがあるときはスペース本来の動作を優先する（横取りしない）。
- スペースを押している間は**テキスト選択を止める**。選択が始まるとブラウザの選択オートスクロールがパンと競合し、長い文書で画面が上下にちらつくため。スペースを押していないときの選択・ドラッグは通常どおり。
- PDF はブラウザ標準ビューアに委ねるため対象外。

## ライブリロード

- 開いているファイルの更新を 0.5 秒間隔で検知して自動再描画（バックグラウンドタブでは停止）。
- **変更箇所へ自動スクロール**：直前との差分から最初の変更行を特定し、その要素を画面上から約 20% の位置へスクロール。
- **追記・編集時は黄色背景でハイライト**（フェード）。削除（内容が減る変更）ではハイライトしない。
- スクロール位置は **ファイル × 表示モード（レンダリング / ソース）** ごとに保持する。タブを閉じて開き直しても復元される。

## ディレクトリツリーの自動更新

- ファイルの**追加 / 削除 / リネーム**を反映するため、ツリーを 2.5 秒間隔で再走査（バックグラウンドタブでは停止）。
- **ディレクトリの展開時**・**ファイルのクリック時**にも再走査するので、操作した瞬間に最新の一覧へ更新される。
- 構成に変化が無ければ再描画しない（**ちらつき防止**）。変化時も**展開状態・スクロール位置・選択中ファイル**を保持。
- CSS / marp テーマファイルの増減も再走査時に反映（「表示」セレクトの選択肢が更新される）。

## リンク

- **外部リンク**（`http:` 等）→ ブラウザの別タブ。
- **内部相対リンク**（`.md` / `.pdf`）→ アプリ内タブ（仮選択）で開く。仮選択中のタブからリンクをたどると、元タブは確定に昇格。
- 画像など非対応の内部リンク → blob でブラウザ別タブ。
- 同一文書内アンカー（`#...`）→ 既定どおりスクロール。
- 日本語・空白を含むパスもデコードして解決。

## 印刷 / PDF 出力

- ヘッダーの **印刷ボタン**、右クリックメニュー、または **Ctrl + P** で、**コンテンツのみ**を印刷（ブラウザの「PDF に保存」で PDF 化）。
- `@media print` で背景グレーやカードの影を除去してクリーン出力。`print-color-adjust: exact` で選択 CSS の背景色（見出し帯・コード背景）も印刷。
- 標準は左右マージンをコンテンツ padding で確保（印刷ダイアログのマージン設定に依存しない）。marp はスライド 1 枚＝1 ページ（フルブリード）。
- 保存先フォルダはブラウザの仕様上、Web ページからは指定不可（ユーザーがダイアログで選択）。

## 右クリックメニュー

角のない矩形メニューで、**操作 → タブ操作 → コピー → 非表示** の順にグループを区切って並べる。

| 右クリックした場所 | 項目 |
|---|---|
| ツリーの**ファイル** | 開く / 右（左）のペインで開く ─ 相対パスをコピー / ファイル名をコピー ─ アイテムを非表示 / サイドバーを閉じる |
| ツリーの**フォルダ** | 相対パスをコピー / ファイル名をコピー ─ アイテムを非表示 / サイドバーを閉じる |
| ツリーの**余白** | 非表示にしたものを表示する（N 件） ─ サイドバーを閉じる |
| **タブ** | 右（左）のペインへ移動 ─ 閉じる / 他のタブを閉じる / すべてのタブを閉じる ─ 相対パスをコピー / ファイル名をコピー |
| **プレビュー本文** | **戻る** / **進む** / **更新** / ソース ⇄ レンダリング切替 / 右（左）のペインへ移動 ─ ソースをコピー（全体・選択範囲）/ 相対パス・ファイル名をコピー ─ 印刷 / PDF 出力 |
| **見出しサイドバー** | サイドバーを閉じる |

- 「右（左）のペインで開く」は、**未オープンならそのペインで開き、開いていればそのペインへ移す**（未分割なら分割してから）。
- 「戻る」「進む」「更新」はヘッダーの ← → ⟳ と同じ動作（そのタブのリンク遷移履歴 / 再走査＋再描画）。履歴が無いときは**グレー表示で実行できない**項目として出る。
- サイドバーの開閉は **「サイドバーを閉じる」**（個々のファイルを隠す「アイテムを非表示」と区別するため、別の表現にしている）。開閉ボタンの tooltip も「サイドバーを閉じる / サイドバーを開く」。

## コピー

- ツリー / タブ / プレビュー上の右クリックで：
  - **相対パスをコピー** / **ファイル名をコピー**
- プレビュー右クリックで：
  - **ソースをコピー（全体）**
  - **ソースをコピー（選択範囲）** … レンダリング表示の選択は HTML→Markdown 変換（テーブル・コードフェンス等を復元）、ソース表示の選択は生テキスト。
- 画像・動画の上で右クリックすると：
  - **画像をコピー** … canvas 経由で PNG 化してクリップボードへ（クリップボードは PNG しか広く保証されないため）。
  - **現在のフレームを画像コピー** … 動画は Clipboard API が対応する MIME 型に無いため、再生中のフレームを PNG として書き出す。
- コピー成否はトーストで通知。

## サイドバーの開閉・リサイズ

- 開閉ボタンは**ヘッダー行**にある。**開いている間はそのサイドバーのヘッダー**（左＝フォルダ名の左、右＝見出しペインの左端）、**閉じている間はメインのツールバー**（左端 / 右端）へ移動する。
- 分割線（スプリッタ）は**ドラッグして幅を変える**専用（クリックでの開閉は開閉ボタンに集約）。
- **右クリックメニューからも閉じられる**。ファイルツリー（項目上・余白どちらでも）と見出しサイドバーの右クリック →「サイドバーを閉じる」。

- 左右サイドバーはスプリッタ中央の**ハンドル**で開閉（クリック）・リサイズ（ドラッグ）。
- 閉じるとスプリッタが細いレールとして残り、ハンドルで再展開。
- 幅・開閉状態は `localStorage` に保存。
